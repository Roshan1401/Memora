# Memora 📓

Memora is a monthly notes-tracking app built for people who love journaling. Organize your thoughts, entries, and reflections month by month in a clean, distraction-free interface.

🔗 **Live demo:** [memora-five-beta.vercel.app](https://memora-five-beta.vercel.app)

## Features

- 📅 Organize journal entries by month
- 📝 Simple, clean note-taking interface
- ⚡ Fast, responsive experience powered by Next.js
- 🎨 Modern styling with Tailwind CSS / PostCSS

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** TypeScript
- **Styling:** PostCSS (Tailwind CSS)
- **Linting:** ESLint
- **Deployment:** [Vercel](https://vercel.com/)

## Getting Started

### Prerequisites

- Node.js (v18 or later recommended)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Roshan1401/Memora.git
   cd Memora
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Run the development server
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

## Deployment

This project is deployed on [Vercel](https://vercel.com/). To deploy your own version:

1. Push your fork to GitHub.
2. Import the repository into [Vercel](https://vercel.com/new).
3. Vercel will detect the Next.js framework automatically and deploy it.

See the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
